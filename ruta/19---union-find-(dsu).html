19 · Union-Find (DSU)

Estructuras y algoritmos avanzados · Ruta de Aprendizaje

Esta clase explica cómo mantener grupos conectados. La ficha DSU (Union-Find) desarrolla la implementación completa y sus detalles.

Antes de empezar. Representar componentes de un grafo: 15 - Grafos I - BFS y DFS; funciones recursivas: 09 - Recursión.

🎯 Objetivos

Al terminar este módulo sabes:

  • Mantener grupos que se fusionan con costo casi constante.
  • Responder “¿están en el mismo grupo?” y “¿de qué tamaño es?” al vuelo.
  • Distinguir cuándo DSU le gana al DFS del módulo 15.

📖 La lección

El problema que resuelve

Con DFS cuentas componentes de un grafo fijo. Pero si las conexiones van apareciendo (se construye una carretera, dos personas se hacen amigas) y entre medio te preguntan por los grupos, rehacer el DFS para q consultas puede costar O(q·(n+m)), con n nodos y hasta m aristas. El Disjoint Set Union mantiene los grupos al día en tiempo casi constante por operación.

Cómo funciona

Cada grupo tiene un jefe (representante). Cada elemento apunta hacia su jefe a través de una cadena; dos elementos están en el mismo grupo si tienen el mismo jefe.

Desliza el diagrama para verlo completo.

Los dos trucos — compresión de camino (al buscar, re-apunta todo directo al jefe) y unión por tamaño (el chico se cuelga del grande) — dejan cada operación con costo amortizado O(α(n)), prácticamente constante. «Amortizado» describe el costo promedio sobre una secuencia de operaciones, no que cada llamada haga exactamente el mismo trabajo. El tamaño del grupo de x es tam[find(x)]: solo el representante mantiene el tamaño actualizado. Referencia completa: DSU (Union-Find).

Desliza el diagrama para verlo completo.

Antes de unir o consultar, llama iniciar(n). En la tabla usamos nodos 1..n y dejamos el 0 sin usar. Por ejemplo, después de iniciar(6) y unir(1, 2), find(1) == find(2) es verdadero y tam[find(2)] vale 2.

Sigue una secuencia completa (parten 6 elementos, cada uno jefe de sí mismo):

operaciónfind de cada ladoqué pasagrupos después
unir(1, 2)1, 2jefes distintos, tamaños iguales: 2 bajo 1{1,2} {3} {4} {5} {6}
unir(3, 4)3, 44 bajo 3{1,2} {3,4} {5} {6}
unir(2, 4)1, 3tamaños 2 y 2: 3 bajo 1{1,2,3,4} {5} {6}
unir(5, 6)5, 66 bajo 5{1,2,3,4} {5,6}
unir(1, 3)1, 1mismo jefe: devuelve false (cerraría un ciclo)sin cambios
unir(6, 4)5, 1tamaños 2 y 4: 5 bajo 1{1,2,3,4,5,6}

Ese false de la quinta fila detecta ciclos al insertar aristas en un grafo no dirigido: una arista que une dos nodos que ya estaban en el mismo grupo cierra un ciclo. Es el corazón de Kruskal (MST).

En la cadena 4→3→1, find(4) llama a find(3), que llega a la raíz 1. Al volver, guarda jefe[3]=1 y luego jefe[4]=1. Las pertenencias no cambian: solo se acorta el recorrido de futuras consultas. No necesitas calcular α(n) para usar la estructura; sí conservar ambas optimizaciones.

Para contar componentes desde main, después de definir las funciones:

La conexión 1–3 no reduce el contador porque esos nodos ya estaban juntos. DSU no detecta con este criterio los ciclos dirigidos: para ellos usamos, por ejemplo, Kahn.

Dónde brilla

Conectividad incremental (“después de cada carretera, ¿cuántas provincias?”), detectar si una arista cierra ciclo, y — más adelante — es el corazón de Kruskal (MST). Si el grafo es fijo y la pregunta es una sola, el DFS sigue siendo suficiente; DSU gana cuando el grafo evoluciona.

🏋️ Práctica

Práctica directa: Carreteras que unen grupos

Empieza con 4 nodos. Inserta 1–2,2–3,1–3,3–4; después de cada arista imprime el número de componentes. Salida: 3 2 2 1.

Idea para comprobar tu solución

Reduce el contador solo si unir devuelve true. La tercera carretera agrega una arista, pero no fusiona grupos.

Para pensar: el bosque de DSU no es el grafo

Insertas las aristas A–B y B–C. DSU informa que A y C están conectados. ¿Significa que existe una arista A–C? Si ahora eliminas B–C, ¿basta con consultar de nuevo el mismo DSU?

Ver razonamiento

Conectados significa que existe un camino: aquí es A–B–C. Los padres de DSU representan grupos; no tienen por qué ser aristas del grafo original. El DSU básico fusiona grupos al insertar aristas, pero no sabe dividirlos cuando una arista desaparece. Tras eliminar B–C seguiría diciendo que A y C están juntos. Para consultar el grafo resultante en este caso pequeño, se pueden recalcular sus componentes con DFS o BFS.
